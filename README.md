## Quick 2-Minute Deployment Instructions:

1. **Create GitHub Repository:**
   - Go to [GitHub](https://github.com/new).
   - Name the repository: `pdfbolt.github.io` (or create a repository named `pdfbolt-docs`).
   - Set visibility to **Public**.

2. **Upload `index.html`:**
   - Push the contents of the `github-pages/` folder (`index.html`) to the root of your `pdfbolt.github.io` repository on the `main` branch:
     ```bash
     cd github-pages
     git init
     git remote add origin https://github.com/<your-username>/pdfbolt.github.io.git
     git add .
     git commit -m "feat: launch PDFBolt architecture & entity hub"
     git branch -M main
     git push -u origin main
     ```

3. **Verify Deployment:**
   - Go to Repository **Settings** -> **Pages**.
   - Ensure the Source is set to **Deploy from a branch** -> `main` / `root`.
   - Your site will be live instantly at `https://pdfbolt.github.io/` providing high-authority dofollow links to all major PDFBolt tools!
